# Speaker Timer

A full-screen, color-changing countdown for timed speaking turns in virtual meetings (Zoom, Microsoft Teams, Google Meet) or in a room on a projector.

- **Green**: plenty of time.
- **Yellow**: time to start wrapping up (choose 10 seconds to 2 minutes before the end).
- **Red**: time is up; the clock counts the extra time, for example +0:15.

## How to use

1. Open the link and choose the time per speaker: 3, 4 or 5 minutes, or type your own (3 minutes minimum).
2. Choose when the screen turns yellow, and optionally type the speaker's name.
3. Press **Start** (or the Space bar). Press **Next speaker** (or N) when the turn ends.
4. In Zoom, click **Share Screen** and pick the browser window showing the timer. Tick **Share sound** if you want others to hear the optional chime.

The controls fade while the timer runs, so participants see only the clock. Move the mouse to bring them back.

**Keyboard shortcuts:** Space start or pause · R reset · N next speaker · F full screen · 3 to 9 set minutes.

## Details

- One self-contained file (`index.html`): no installation, no sign-in, no tracking.
- Works in any modern browser on Windows, Mac and Chromebook computers.
- Time and warning choices are remembered on each person's own computer.
